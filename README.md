# 類《三國志 IX》App 小遊戲企劃（戰爭核心版）

> 目標：做一款「像《三國志 IX》節奏」的手機策略小遊戲。  
> 本版重點：**內政簡化**、**戰爭深度**、**武將特色**、**兵種相剋與陣型博弈**。

---

## 1) 核心體驗（以戰爭為主）

1. **大地圖即時推進**：部隊在同一張地圖行軍、遭遇、攻城。  
2. **戰前編制決策**：誰帶隊、帶什麼兵、用什麼陣型，比純兵力更重要。  
3. **戰場剋制循環**：兵種相剋 + 地形 + 士氣 + 武將戰法決定勝負。  
4. **短局高張力**：每局 20–40 分鐘，聚焦「打仗是否精彩」。

---

## 2) 遊戲循環（3 步）

1. **整軍（每月）**：徵兵、編隊、任命主副將、選陣型。  
2. **出征（每旬）**：推進戰線、截糧道、野戰、圍城。  
3. **結算（每月）**：資源入帳、武將體力與忠誠變化、事件觸發。

---

## 3) 系統設計（簡政重戰）

### 3.1 地圖與勝利
- 城市：24 座
- 關隘／港口：30 個
- 初始勢力：8 家
- 勝利條件：
  - 佔領 16 城；或
  - 240 月總評第一

### 3.2 內政（簡化成 4 個按鈕）
> 每城每月僅可執行 **1 次內政指令**，避免拖節奏。

- **徵兵**：+300~900 預備兵（受民心、治安影響）
- **屯糧**：+1500~3000 糧
- **募資**：+1000~2200 金（民心小幅下降）
- **安民**：+20~40 民心、+20 治安

城市保留兩項核心值即可：
- 民心（0–100）
- 治安（0–100）

每月基礎產出：
- 金：`1200 + 城市等級*200`
- 糧：`1800 + 城市等級*300`

### 3.3 武將特色（主系統）
每位武將四維（1–100）：
- 統率、武力、智略、政略

新增「戰鬥個性」欄位（讓武將有手感差異）：
- **猛將型**：突擊傷害 +12%，但計略抗性 -8%
- **軍略型**：戰法成功率 +10%
- **守將型**：守城防禦 +15%
- **疾行型**：行軍速度 +12%

忠誠（0–100）：
- <60 容易被離間；<40 有機率叛逃

體力（0–100）：
- 出征每旬 -15、待命每旬 +12

### 3.4 兵種與相剋（戰鬥核心）
兵種：槍兵、騎兵、弓兵、戟兵、器械

相剋倍率建議：
- 槍兵 > 騎兵：`1.2`
- 騎兵 > 弓兵：`1.2`
- 弓兵 > 槍兵：`1.2`
- 戟兵對全兵種：`1.0`（萬用中庸）
- 器械對城防：`1.5`，對野戰：`0.75`

被剋制方統一倍率：`0.85`

### 3.5 陣型系統（新重點）
每支部隊出征前必選 1 種陣型：

1. **魚鱗陣（平衡）**
   - 攻 +5%、防 +5%、速 0
2. **鋒矢陣（突擊）**
   - 攻 +15%、防 -12%、速 +5%
3. **方圓陣（防禦）**
   - 攻 -8%、防 +18%、受計略傷害 -10%
4. **鶴翼陣（包抄）**
   - 側擊機率 +20%、正面交戰防禦 -8%
5. **長蛇陣（機動）**
   - 行軍速度 +15%、初戰士氣 +10、持久戰 -10%

> 陣型克制建議（可後續平衡）：
- 鋒矢克方圓（破防）
- 方圓扛鶴翼（抗包抄）
- 鶴翼克魚鱗（側翼）
- 魚鱗克長蛇（穩定交戰）
- 長蛇克鋒矢（拉扯反打）

### 3.6 戰鬥公式（可直接實作）

`最終傷害 = 攻擊基值 × 兵力係數 × 兵種倍率 × 陣型攻擊倍率 × 陣型克制倍率 × 地形倍率 × 士氣倍率 × 隨機(0.9~1.1)`

- 攻擊基值：`25 + 統率*0.5 + 武力*0.5`
- 兵力係數：`當前兵力 / 1000`
- 地形倍率：
  - 平原 1.0、山地 0.85（騎兵 0.75）、森林 0.9（弓兵 1.1）
- 士氣倍率：0.7 ~ 1.3

### 3.7 戰法與計略（讓智將有存在感）
TP（計略點）每月回復：`30 + 智略最高武將/10`

戰法／計略：
- 突擊（40 TP）：瞬間高傷，鋒矢陣加成 +15%
- 擾亂（45 TP）：敵方士氣 -18
- 火計（70 TP）：持續 2 旬灼燒（森林/平原可用）
- 偽報（55 TP）：敵軍行軍延遲 1 旬
- 斷糧（80 TP）：敵軍每旬額外耗糧 +40%

成功率：
`55% + (我方智略 - 目標智略)*0.7%`（上限 90%、下限 15%）

### 3.8 攻城與補給
- 城池耐久：`9000 + 城防等級*1500`
- 圍城糧耗：攻方每千兵 130／守方每千兵 95
- 斷糧效果：
  - 士氣每旬 -20
  - 傷害 -25%
  - 連續 2 旬有機率潰逃

### 3.9 AI 難度
- 普通：資源 x1.0，進攻傾向 35%
- 困難：資源 x1.15，進攻傾向 50%
- 修羅：資源 x1.3，進攻傾向 65%，優先斷補給與夾擊

## 7) 開發原則（你這版需求對應）
- 內政保持「不煩」：每月 1 次操作就好。
- 戰爭做「可讀可算」：玩家要知道為何贏、為何輸。
- 武將做「有臉譜」：同兵力換將，體感要不同。
- 優先平衡：兵種相剋 > 陣型博弈 > 戰法強度。

## 8) 程式原型（本 repo 已實作）

目前已提供可執行的戰鬥核心與手動測試程式：
- `src/battle_engine.py`：傷害公式、兵種/陣型相剋、地形、士氣、回合交戰模擬、戰法成功率
- `src/game.py`：對局狀態管理、勝負判定、內政（徵兵/屯糧/募資/安民）
- `src/gui.py`：Tkinter 圖形化介面（可手動選陣型、地形、內政並跑回合）
- `src/main.py`：CLI 入口（demo / interactive / gui）
- `tests/`：pytest 測試（戰鬥核心、流程、內政、輸入解析）

執行方式：

```bash
python3 -m src.main --mode demo
python3 -m src.main --mode interactive --max-rounds 8 --seed 7
python3 -m src.main --mode gui --max-rounds 8 --seed 7
pytest --cov=src --cov-report=term-missing
```

手動測試建議流程：
1. 先用 `--mode demo` 檢查環境可執行。
2. 再用 `--mode gui` 進行圖形化手動測試（陣型、地形、內政）。
3. 若要重現問題，固定 `--seed` 後回報戰報文字即可重播。
